# Vectorized Cross-Sectional Equity Backtester (Nifty 50)

## Summary
This repository contains a vectorized cross-sectional equity backtesting framework evaluated on the constituents of the Nifty 50 index (49 stocks after excluding `TATAMOTORS` due to demerger data anomalies) using daily auto-adjusted Yahoo Finance data from 2015 to 2026. The framework evaluates classic quantitative factor signals—momentum, short-term reversal, and low volatility—by computing cross-sectional factor scores, converting them into dollar-neutral portfolio weights scaled to gross exposure 1.0, and executing trades with a 1-day lag to eliminate look-ahead bias. Portfolio performance is modeled net of a 5 bps turnover-based transaction cost alongside rank Information Coefficient (IC) and multi-horizon IC decay metrics to evaluate true alpha persistence.

## Findings
1. Reversal generates the highest raw rank Information Coefficient among all tested factors, but its roughly 60% daily turnover completely erodes performance once a modest 5 bps transaction friction is accounted for.
2. Momentum displays slower information decay that expands across longer holding periods, making lower-frequency monthly rebalancing (every 21 days) substantially more cost-effective.
3. The low-volatility factor did not perform well in this sample, and its standard academic definition was preserved without arbitrarily flipping the sign to engineer positive in-sample returns.

## Methodology

1. **Signal Formulation**:
   - **Momentum** (`momentum`): Evaluates 12-month returns while skipping the most recent 21 trading days (`close.shift(21) / close.shift(252) - 1`) to avoid contamination from short-term mean reversion.
   - **Reversal** (`reversal`): Computes the negative of the 5-day percentage change (`-close.pct_change(5)`), betting that recent short-term underperformers will rebound.
   - **Low Volatility** (`low_vol`): Computes the negative of the 60-day rolling return standard deviation (`-close.pct_change().rolling(60).std()`), favoring historically calmer equities.

2. **Cross-Sectional Ranking & Demeaning**:
   - On each trading day $t$, available stocks are assigned percentile ranks between 0 and 1:
     $$\text{ranks}_t = \text{rank}(\text{signal}_t)$$
   - Ranks are demeaned across the cross-section to create an equal balance between long and short positions:
     $$w_t^{\text{demeaned}} = \text{ranks}_t - \overline{\text{ranks}}_t$$

3. **Dollar-Neutral Gross Exposure Scaling**:
   - Demeaned weights are scaled by their absolute sum across all assets so that total gross exposure equals 1.0 (0.5 long, 0.5 short):
     $$w_t = \frac{w_t^{\text{demeaned}}}{\sum_{i} |w_{i,t}^{\text{demeaned}}|}$$
   - For rebalance intervals $N > 1$, weights are sampled every $N$ trading days and forward-filled until the subsequent rebalancing date.

4. **Execution Timing & Look-Ahead Prevention**:
   - Signals and weights calculated at market close on day $t$ are shifted forward by 1 trading day (`w.shift(1)`), applying them to returns observed between $t$ and $t+1$ to strictly eliminate look-ahead bias.

5. **Transaction Costs**:
   - Portfolio turnover is measured as the sum of absolute weight shifts across all universe constituents:
     $$\text{Turnover}_t = \sum_{i} |w_{i,t} - w_{i,t-1}|$$
   - Net returns subtract transaction costs modeled at 5 basis points (0.05%) per unit of turnover:
     $$\text{Net PnL}_t = \text{Gross PnL}_t - \text{Turnover}_t \times \frac{5}{10000}$$

6. **Evaluation Metrics**:
   - **Performance**: Annualized return ($252 \times \bar{r}$), annualized volatility ($\sqrt{252} \times \sigma$), Sharpe ratio ($\text{Return} / \text{Vol}$), and maximum drawdown from compounded cumulative wealth.
   - **Information Coefficient (IC)**: Daily Spearman rank correlation between factor values and forward $h$-day returns ($\text{corr}(\text{rank}(\text{signal}_t), \text{rank}(r_{t \to t+h}))$), IC Information Ratio ($\text{Mean IC} / \text{Std IC}$), percentage of positive days, and multi-period decay analysis.

## Limitations
- **Survivorship Bias**: The asset universe is defined using current Nifty 50 constituents as of the download date rather than point-in-time historical index membership. Stocks removed or acquired prior to the end date are absent.
- **Demerger Omission (`TATAMOTORS`)**: Tata Motors was omitted because corporate actions and demerger events caused Yahoo Finance to return complete NaN price series across the backtest window.
- **Data Quality**: Pricing data originates from free Yahoo Finance auto-adjusted feeds, which can contain occasional corporate split/dividend inaccuracies, timing mismatches, or missing volumes.
- **Absence of Out-of-Sample / Walk-Forward Validation**: The entire 2015–2026 dataset is evaluated in a single pass; no separate out-of-sample holdout or rolling walk-forward cross-validation has been implemented.
- **Multiple-Testing Bias**: Several signal variations, lookback windows, and rebalancing horizons were evaluated iteratively on the exact same dataset, increasing the probability that selected parameters reflect data snooping rather than structural alpha.

## How to Run

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Download Historical Data**:
   > **Note**: The `data/` directory is gitignored and does not come pre-packaged with the repository. You must run the download script first to pull price and volume data.
   ```bash
   python3 download50.py
   ```
   This will download auto-adjusted daily OHLCV series for Nifty 50 tickers from 2015 to the present and save `data/close.parquet` and `data/volume.parquet`.

3. **Run Backtester**:
   ```bash
   python3 main.py
   ```
   This will execute the factor strategies, print performance and rank IC decay tables to stdout, and display cumulative equity curves.
